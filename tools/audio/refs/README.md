# The cast's reference voices

VoiceStudio's engines clone a voice from a short recording. These are the
recordings the cast is cloned from (`record.py`).

| File | What it is | Licence |
| --- | --- | --- |
| `ng_07049_hot.flac` (+ `.txt`, its words) | Dr. Okoro: four of the most energetic recordings of speaker 07049 in Google's *Crowdsourced high-quality Nigerian English speech data set* (OpenSLR 70, https://www.openslr.org/70/), joined | CC BY-SA 4.0 (Google) - and so are Okoro's lines made from it |
| `vale.flac` | Dr. Vale (and the pilot): a voice designed with OmniVoice - "male, middle-aged, very low pitch, british accent" | Made with OmniVoice (weights CC BY-NC 4.0) |
| `trailer.flac` | The briefing's trailer voice: OmniVoice, "male, middle-aged, very low pitch, american accent" | As above |
| `you-f.flac`, `you-m.flac` (+ `.txt`) | Subject 07, as each character: OmniVoice, "female/male, young adult, moderate pitch, american accent" | As above |
